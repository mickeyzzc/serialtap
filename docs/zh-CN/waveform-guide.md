# 波形观测指南

[English](../en/waveform-guide.md) | [简体中文](waveform-guide.md)

面板（`serialtap run` 内置，默认 http://127.0.0.1:8801/）的「波形」tab 是一台
**通用示波器**：把串口遥测行里的数字变成滚动波形。本文是从零到会读图的完整
教程；面板右上角的 **?** 里有一份精简版（同样的内容，随手可查）。

## 三步上手

1. 左侧**点设备卡片**选中要看的板子
2. 点「**波形**」tab
3. 看图——不需要任何配置

面板自动识别遥测行并把数字画出来。只有当自动通道不合意时才需要
「高级提取…」，而且全程有实时试跑兜底，不会写正则也用得上自动模式。

## 自动识别是怎么工作的

嵌入式固件通常按固定格式周期输出一行遥测，比如：

```
#S1 1117 27762 -49 09fb0e0212ff0a050e080803...
```

面板按**行首记号**（帧型，如 `#S1`）给行分组，取近 5 秒**最活跃**的帧型
绘制——偶发的心跳/握手行（如 `#S1-HELLO`、`I (1234)`）自动让位。行内记号
的归类规则：

| 记号形态 | 通道 | 例 |
|---|---|---|
| `key=数字` | **命名通道**（用 key 当名字） | `t=23.4` → 通道 `t` |
| 纯数字 | **位置通道**（`v2`、`v3`… 按记号次序） | `-49` → 通道 `v3` |
| 十六进制块 / 文本 | **自动排除**（不是纯数字） | `09fb0e02…` |

> 为什么十六进制块不会被画：它含 `a-f` 字母，不满足"纯数字"判定，
> 天然排除——不需要用户配置。CSI 幅值数组这类二进制载荷不适合直接当
> 波形看，它的解读是上层业务（如 homepulse 感知）的事。

通道数上限 6；帧内数字个数漂移时通道标签自动跟随。

## 自定义提取（高级）

三种典型场景需要自己定义通道：

1. **只要其中一路**：自动画了 3 个通道，但你只想盯 RSSI
2. **量纲/分组不理想**：想按自己的语义分组而不是按位置
3. **行格式特殊**：自动识别不命中

### 操作流程

点波形工具条的「**高级提取…**」：

1. **挑模板**（点击填入，可再改）：`#S1 取 RSSI`、`行内第一个数字`、
   `行内全部数字`、`t=/h= 双通道`
2. **改正则**，看下方**实时试跑**：对当前设备最近 20 行原始日志逐行提取，
   左边是提取出的通道值、右边是原文——应用之前就能看见每行会提出什么
3. **应用并绘制**（或**恢复自动识别**随时退回）

### 正则写法速查

每个**捕获组**（一对括号）= 一个通道；正则不带捕获组时，行内全部命中
各为一通道（≤6）。面板给每行加的 `[时间戳]` 前缀已自动剥离——正则对准
**板子原始行**写。

| 想看什么 | 正则 | 说明 |
|---|---|---|
| #S1 行的 RSSI（第 3 个数） | `#S1 \d+ \d+ (-?\d+)` | 一个捕获组 |
| 温度 + 湿度双通道 | `t=([\d.]+)\s+h=([\d.]+)` | 两个捕获组 = 两个通道 |
| 行内第一个数字 | `(-?\d+(?:\.\d+)?)` | 捕获组包裹要取的值 |
| 行内全部数字 | `-?\d+(?:\.\d+)?` | 无捕获组 → 命中各为一通道 |
| 只要浮点数（滤掉整数计数） | `(-?\d+\.\d+)` | 计数器是整数，天然滤除 |

语法要点：`\d` 数字、`[\d.]` 数字或小数点、`( )` 捕获组、`-?` 可选负号、
`\s+` 空白。正则非法时输入框下立刻标红；写错按子串理解的情况不存在——
这里只按正则解析，非法就是非法，看得见。

## 怎么读波形

### 泳道

**每个通道一条泳道**，互不挤压：泳道左上角标注**通道名、当前值、区间**
（min~max，含 8% 余量）。曲线贴到泳道顶/底说明触到了区间边界——当前
时间窗内该通道的极值。

### 包络与中心线

曲线由**每像素 min/max 包络 + 中心线**构成：横轴一个像素内的所有样本，
取最小/最大画成填充包络，均值画成中心线。高频数据（几十 Hz）下：

- 包络的"毛边"是**真实的波动幅度**，不是噪声
- 中心线是**趋势**：缓漂、骤降、台阶都看它
- 一条细线（包络很窄）= 该窗口内数值几乎不变

### 采样率与窗口

顶栏的 **Hz** 是采样速率（每秒多少行命中并提取）。时间窗 15s / 60s /
5min / 30min 可选：窗口越长看得越久、细节越糊；越短越锐。

### 悬停、冻结、清除、导出

- **悬停**：十字线跨所有泳道，同时读该时刻各通道值，底部显示时间偏移
- **冻结**：停采样定格画面（窗口停在冻结时刻），方便细看或截图；
  再点恢复
- **清除**：清空样本缓冲
- **导出 CSV**：样本按 `t_ms,ch1,ch2…` 落盘，带通道名表头，可进
  Excel/Python 复分析

### 读图案例

- **RSSI 泳道**：缓慢漂移 = 信道/环境变化；骤降 = 干扰或遮挡；周期性
  起伏 = 有东西在周期性移动（这也是 CSI 感知的基本信号）
- **计数类通道（v1/v2）**：单调递增呈斜线是**正常**的。斜率不变 =
  流速稳定；斜率归零 = 丢行或固件停发；斜率突变 = 重启过（配合事件
  时间线的复位刻度可对上）
- **温度/湿度类**：中心线的缓变台阶即事件（开空调、人靠近），包络宽度
  即传感器抖动
- **全平直线 + 静默指标变红**：板子不输出了——先看设备卡的「静默」和
  「重开」，再用「软重连」救

## 常见问题

| 症状 | 处置 |
|---|---|
| 波形区空白 | 设备没有输出"含数字的行"。等几秒；确认全量 tab 里有遥测行 |
| 只有斜线（计数通道） | 正常——用「高级提取」只取关心的那路 |
| 通道比预期少 | 行内纯数字记号 >6 个时截断；十六进制块不参与（设计如此） |
| 自动选错了帧型 | 心跳行偶发占优时会自行切回；等 5s 窗口滑过，或用自定义提取锁死 |
| 自定义后不画了 | 正则命中 0 行——试跑区会显示"命中 0/20 行"，按原文调整 |
| 画面定格不动 | 点了「冻结」——再点一次恢复 |
