三个页面 + 配置

      
打开即落在多机日志工作台（首页用来干活）；顶部导航切换，#logs / #wave / #dash 可直达：

      

        
页面干什么

        
日志（首页）多机同时看日志 + 全局操作台：勾选多台设备，并排（每台一个窗格）或合并（按时间交织、每台保底配额防刷屏，每行带彩色设备标签）；窗格头部直接暂停/恢复、软重连、刷机、波形（本地与 mesh 远端同权）；「全选/清空」一键改选，点设备卡或窗格标题 = 只看这台；搜索/正则过滤与高亮跨设备生效

        
波形多机同时看波形：多机网格每台一块实时示波器；「大图」进单机分析（冻结/悬停读值/高级提取/导出 CSV），大图里用设备下拉随时换台

        
仪表盘全网健康总览（参考页）：KPI 指标条（设备数/采集中/吞吐/异常/事件/mesh 节点）、设备卡（常用操作一键直达，诊断类收进「更多」菜单）、30 分钟事件时间线、mesh 节点管理、运行配置速览

        
⚙ 配置头部按钮打开只读配置速览：日志目录/波特率/轮询/轮转与保留期、刷机编排（esptool/超时）、事件签名、命名与排除规则、mesh（密钥只显示指纹）——改配置需编辑配置文件并重启守护

      

      
所有设备（含 mesh 远端）都在后台持续采样与缓冲——勾选、切换、换页都不会丢数据。

波形自动识别是怎么工作的

      
板子通常按固定格式周期输出一行遥测（如 #S1 1117 27762 -49 09fb0e…）。
      面板按行首记号（帧型，如 #S1）给行分组，取近 5 秒最活跃的帧型绘制，偶发的心跳/握手行自动让位。行内：

      

        
记号形态通道例

        
ESP-IDF 日志行帧型 级别·tag；开机 tick + 行内独立数字I (2944) st7735: retry 3 → I·st7735

        
key=数字命名通道（全局聚合：哪个 tag 输出的都进同一条泳道，低频测量不会被高频帧挤掉；带单位 T=28.1C 亦认可）t=23.4 / T=28.1C → 通道 t / T

        
纯数字位置通道（v2、v3…按记号次序）-49 → 通道 v3

        
十六进制块 / 文本自动排除09fb0e02…

      


      
自定义提取（高级）

      
三种典型场景：只要其中一路（如只看 RSSI）；量纲差异想精确分组；行格式特殊自动识别不理想。
      波形「单机大图」里点「高级提取…」→ 挑模板或手写正则 → 看实时试跑确认每行提出什么 → 应用。提取策略按设备各自记忆，回到网格也生效。

      

        
想看什么正则说明

        
#S1 行的 RSSI（第 3 个数）#S1 \d+ \d+ (-?\d+)一个捕获组 = 一个通道

        
温度 + 湿度双通道t=([\d.]+)\s+h=([\d.]+)两个捕获组 = 两个通道

        
行内第一个数字(-?\d+(?:\.\d+)?)捕获组包裹要取的值

        
行内全部数字-?\d+(?:\.\d+)?无捕获组 → 命中各为一通道

      

      
要点：正则对准板子原始行（面板的 [时间戳] 前缀已剥离）；\d 数字、
      [\d.] 数字或小数点、( ) 捕获组、-? 可选负号。试跑区左边是提取值、
      右边是原文，确认无误再应用。


      
怎么读波形

      
每个通道一条泳道，互不挤压：左上角是通道名、当前值和区间（min~max，含余量）——
      泳道内曲线贴顶说明触到区间上沿。曲线是每像素 min/max 包络 + 中心线：高频数据下
      包络的"毛边"是真实的波动幅度，中心线是趋势。Hz 是采样速率（每秒多少行命中）。
      大图里悬停出十字线：跨所有泳道同时读该时刻各通道值，底部显示时间偏移。
      冻结定格显示（后台照常采样，恢复后间隙自动补全），清除清空缓冲。
      时间窗 15s~30min，另有全部——回看自打开面板起保留的全部样本（按条数封顶，
      切页/换窗历史不丢）。

      
读图示例：RSSI 泳道缓慢漂移是信道变化；骤降常是干扰或距离变化；计数类通道（v1/v2）
      呈斜线属正常——它单调递增，斜率不变=流速稳定，斜率突变=丢行或重启。


      
仪表盘健康速览

      
设备卡：静默 Xs（最近读到数据距今，超 30s 变黄、超 5min 变红）、重开 N（断线重开次数，
      ≥3 变红）、写入速率迷你图（2 分钟）。KPI 条的异常设备把静默超 5 分钟或重开 ≥3 的板子计红，
      悬停看名单；事件统计近 30 分钟签名命中（红=崩溃/复位、黄=错误、蓝=生命周期），悬停时间线刻度看原文。
      所有操作按钮与命令行走同一条守护控制通道，行为一致。
