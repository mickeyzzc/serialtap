三步上手

① 左侧点选设备卡片 → ② 点「波形」tab → ③ 看图。无需任何配置： 面板自动识别遥测行并把数字变成通道画出来。想锁定某几路时才需要 「高级提取…」，写不了正则也照样能用自动模式。

自动识别是怎么工作的

板子通常按固定格式周期输出一行遥测（如 #S1 1117 27762 -49 09fb0e…）。 面板按行首记号（帧型，如 #S1）给行分组，取近 5 秒最活跃的帧型绘制，偶发的心跳/握手行自动让位。行内：

记号形态通道例
key=数字命名通道（用 key 当名字）t=23.4 → 通道 t
纯数字位置通道（v2、v3…按记号次序）-49 → 通道 v3
十六进制块 / 文本自动排除09fb0e02…

自定义提取（高级）

三种典型场景：只要其中一路（如只看 RSSI）；量纲差异想精确分组；行格式特殊自动识别不理想。 点「高级提取…」→ 挑模板或手写正则 → 看实时试跑确认每行提出什么 → 应用。

想看什么正则说明
#S1 行的 RSSI（第 3 个数）#S1 \d+ \d+ (-?\d+)一个捕获组 = 一个通道
温度 + 湿度双通道t=([\d.]+)\s+h=([\d.]+)两个捕获组 = 两个通道
行内第一个数字(-?\d+(?:\.\d+)?)捕获组包裹要取的值
行内全部数字-?\d+(?:\.\d+)?无捕获组 → 命中各为一通道

要点：正则对准板子原始行（面板的 [时间戳] 前缀已剥离）；\d 数字、 [\d.] 数字或小数点、( ) 捕获组、-? 可选负号。试跑区左边是提取值、 右边是原文，确认无误再应用。

怎么读波形

每个通道一条泳道，互不挤压：左上角是通道名、当前值和区间（min~max，含余量）—— 泳道内曲线贴顶说明触到区间上沿。曲线是每像素 min/max 包络 + 中心线：高频数据下 包络的"毛边"是真实的波动幅度，中心线是趋势。Hz 是采样速率（每秒多少行命中）。 悬停出十字线：跨所有泳道同时读该时刻各通道值，底部显示时间偏移。 冻结停采样定格画面（窗口停在冻结时刻），清除清空缓冲，时间窗 15s~30min 可选。

读图示例：RSSI 泳道缓慢漂移是信道变化；骤降常是干扰或距离变化；计数类通道（v1/v2） 呈斜线属正常——它单调递增，斜率不变=流速稳定，斜率突变=丢行或重启。

面板其它功能速览

设备卡：静默 Xs（最近读到数据距今，超 30s 变黄、超 5min 变红）、重开 N（断线重开次数， ≥3 变红）、写入速率迷你图（2 分钟）。日志区：搜索框支持正则（写错自动当子串）+ 高亮 + 计数； 「导出」下载当前缓冲，「波形」tab 下导出 CSV。事件面板：30 分钟时间线，红=崩溃/复位、黄=错误、 蓝=生命周期，悬停看原文。底部：多设备对比面板并排尾随。所有操作按钮与命令行走同一条守护控制 通道，行为一致。
